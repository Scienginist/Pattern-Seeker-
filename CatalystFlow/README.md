# CatalystFlow

촉매 연구·생산 담당자 1인을 위한 **Windows 오프라인 생산·QC 관리 앱**.
원료 재고 → 배치·가지 → 실제 공정 → 물질 계보(분할·병합·이동·재처리) → 제품 재고 → QC → 사용자 판정을 한 화면 흐름으로 기록한다.

- 인터넷·계정·서버 불필요. 데이터는 이 PC의 SQLite 파일 하나.
- 과학적 분석(XRD·BET·전기화학 패턴 비교)은 **Pattern Seeker**의 일이다. CatalystFlow는 QC 결과 요약과 원본 파일 **위치**만 기록한다. 두 앱은 코드·데이터를 공유하지 않는다.

## 실행

| 방법 | 설명 |
|---|---|
| `CatalystFlow.exe` | GitHub Actions `CatalystFlow Windows build` 결과물(`CatalystFlow-windows`)을 받아 폴더째 원하는 곳에 두고 실행 |
| `run_catalystflow.bat` | Python 3.10+가 있는 PC에서 소스로 바로 실행 |
| `python -m catalystflow --browser` | pywebview 없이 Edge/Chrome 앱 창으로 실행 |

창은 Windows 10/11에 기본 탑재된 Edge WebView2로 열린다. 화면 파일도 앱 안에 들어 있어 외부 요청이 없다.

## 데이터 위치 (설치 위치와 분리)

```
%LOCALAPPDATA%\CatalystFlow\
  catalystflow.db        운영 데이터(트랜잭션 SQLite, WAL)
  backups\               자동 백업(하루 1회 시작 시, 복원 직전 안전 백업, 이전 버전 변환 전 백업)
  logs\catalystflow.log
```
앱 폴더를 새 버전으로 바꿔도 같은 데이터를 계속 쓴다. 다른 위치를 쓰려면 환경변수 `CATALYSTFLOW_DATA`를 지정한다.

## 화면

| 화면 | 하는 일 |
|---|---|
| 현황 | 진행 배치와 가지별 현재 작업, 다음에 할 일, 작업 일정, QC 의뢰·결과 대기(BET·TGA 장기 분석 표시), 원료·제품 재고와 판정, 작성 중인 초안 |
| 배치 | 맨 위 **다음 행동** 버튼. 가지별 레인에 공정 목록과 물질 칩이 있다. 물질을 클릭해 선택하면(Shift: 범위) 아래 바에 `공정 기록 / 소분 / 합치기 / 가지로 옮기기 / 제품 등록 / 계보`가 나타난다 |
| 원료 | Lot 입고, 실측 잔량 정정, Lot 수정·휴지통·복원, 투입 Lot 변경, 기록 취소 / 실물 반환 |
| 제품 | 잔량, QC 진행, 사용 기록(출하·QC·내부·연구·재처리)과 취소, 이전 산물 결과를 대표 결과로 인정, 판정 |
| QC | 결과 대기 / 의뢰·측정 필요 |
| 기록·백업 | 백업·복원, 초안, 휴지통, 전체 변경 이력 |

## 입력 규칙

- 오른쪽 패널에서 입력한다. 바깥을 클릭해도 닫히지 않는다.
- 입력은 0.5초마다 **초안**으로 자동 저장되고 `초안 자동저장됨 · 아직 등록되지 않음`으로 표시된다.
- 실제 기록은 **등록 버튼(Ctrl+S)**을 눌러야 저장된다. DB 저장이 끝난 뒤에만 `✓ 등록 완료`가 표시된다.
- 저장에 실패하면 입력은 그대로 남고 이유가 표시된다.
- 초안은 `배치|가지|공정|동작` 단위로 따로 저장된다. 다른 공정이나 동작의 초안이 섞이지 않는다.
- 시각을 비워두면 **미기록**으로 남는다. 현재 시각으로 채우려면 `지금` 버튼을 누른다.
- 질량을 비워두면 **미측정**이며 0 g과 다르다. 실측·추정·계산·계획을 구분해서 표시한다.
- 뒤로/앞으로: 상단 ◀ ▶ 또는 Alt+←/→.

## 250 g 배치 예시

1. 원료 → `+ 입고 등록`: IrCl₃ Lot, 1,000 g
2. 현황 → `+ 새 배치` → 배치 화면의 다음 행동 `원료 투입`: Lot 250 g, 산출 "전구체 슬러리" 1,839 g(실측. 모르면 비워두기)
3. 슬러리 칩 선택 → `같은 양으로 소분`: 31개 × 50 g → 미리보기 "총 1,550 g, 잔량 289 g(계산)" → `소분 완료 기록` 한 번으로 도가니 01~31 생성
4. 생산 가지 `전체 선택` → 슬러리 칩만 해제 → `공정 기록`: 열처리, 방식 "제자리 처리", 관찰 "도가니 4개 노란 기체"
5. 도가니 01 클릭 → Shift+04 클릭 → `가지로 옮기기` → 새 가지 "확인군"(예외). 새 소분이 아니다.
6. 정상 27개 선택 → `합치기`: 세척(질산→물→물). 시작만 기록하고 나중에 `완료 기록` → 산출 "세척 케이크"
7. 케이크 → `공정 기록`: 동결건조 → 산출 분말(건조 g)
8. 분말 → `제품 등록` → 필수 QC 6종(XRD·BET·과전압·pH·TGA·XRF) 자동 생성 → 의뢰일·회신 예상일 → 결과 요약·파일 위치·대표성 → `판정`
9. `+ 가지` "잔여 슬러리 연구" → 슬러리 `소분` 2 × 25 g(대상 가지 지정) → 스터링 유/무 공정 → `분석 추가` BET → 1 L 확대를 "계획만"으로 등록(예정일)

잘못 연결한 투입이 있으면 해당 공정의 `연결 정정`에서 그 물질만 빼면 된다(전체가 함께 저장되거나 전혀 저장되지 않음).
완료된 공정도 `수정`할 수 있고, 수정 전·후 값은 `이력`에서 볼 수 있다.

## 개발

```
pip install -r requirements-dev.txt
python -m pytest -q                       # 업무 규칙 시나리오 테스트
python -m catalystflow --no-window --port 8765
node tests/e2e_flow.js http://127.0.0.1:8765 <스크린샷폴더> <백업폴더>   # 실제 화면 흐름(Playwright)
pyinstaller packaging/CatalystFlow.spec --noconfirm
```
