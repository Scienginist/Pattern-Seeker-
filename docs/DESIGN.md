# Pattern Seeker 설계

## 1. 문제와 목표
연구자가 합성 조건과 XRD·BET·XRF·PSA·TGA·pH·전기화학 결과를 머릿속에서 연결하던 부담을 줄입니다. 저장에서 그치지 않고 다음을 목표로 합니다.

- **연결**: 샘플 ↔ 파생·분기·결합 이력 ↔ 합성 단계 ↔ 분석 결과 ↔ 조건·출처
- **비교**: 여러 샘플의 공통 분석과 조건 차이를 한 화면에서 봅니다.
- **판단 경계**: 데이터로 확인되는 패턴과 데이터가 부족해 판단할 수 없는 부분을 구분합니다.
- **AI 가독성**: 기록값, 계산값, 해석, 가설을 분리하고 단위와 출처를 명시해 저장합니다.

## 2. 구조

```
브라우저 (app/static: 바닐라 JS, SVG 그래프)
   │ JSON (127.0.0.1:8765)
Python 표준 라이브러리 서버 (app/server.py)
   │
SQLite (data/pattern_seeker.db) + data/backups + data/files
```

로컬 서버를 두는 이유는 두 가지입니다.
1. 개인 보관소 경로의 파일 존재 여부를 확인하고 읽으려면 서버가 필요합니다. 브라우저만으로는 할 수 없습니다.
2. SQLite에 안전하게 쓰고 백업·복구하려면 서버가 필요합니다.

요청은 전역 락으로 직렬화합니다. 단일 사용자 로컬 앱이므로 복구 중 동시 쓰기를 막는 쪽을 택했습니다.

## 3. 데이터 모델 (스키마 v1)

| 테이블 | 내용 |
|---|---|
| `samples` | 최종 분말 단위 샘플. 색(`color`)은 모든 그래프에서 같은 색으로 씁니다. 소프트 삭제(`deleted_at`) |
| `sample_links` | 관계(DAG, 다대다): `relation`(파생/분기/결합/재처리/기타), `branch_point`(갈라진 시점), 순환 방지 |
| `series`, `series_members` | 연구 묶음. 관계와 독립 |
| `synthesis_steps`, `reagents` | 합성 단계. `params` = `{키:{value,unit,label,source}}`. 시약 제조사 기본 H사(`supplier_source='default'`) |
| `analysis_types` | 분석 종류 레지스트리 (`config.tool/fields/metrics/default_conditions`) |
| `sample_analysis_status` | 샘플×분석 상태. 행이 없으면 “미업로드” |
| `measurements` | 측정 기록: `conditions`, `values`, `computed`, `source`, `measured_on(_source)`, `seq`, `ec_session_id` |
| `datasets` | 원시 곡선(열 배열). 처리 조건(배경점, 스무딩, 단위, 사이클 분리)은 `meta`. 원본은 변형하지 않음 |
| `attachments` | `link`(경로·크기·수정 시각) 또는 `copy`(sha256, data/files). 상태: 확인됨 / 경로 깨짐 / 파일 변경됨 |
| `ec_sessions` | 전극/세션 조건 |
| `interpretations` | `user_interpretation` / `ai_hypothesis` + `evidence`(근거, 조건 차이, 데이터 부족, 불확실성, 다음 측정) |
| `settings` | 기본값 (시약 제조사, 열처리, 전기화학) |
| `audit_log` | 생성·수정·삭제 전후 상태 |

### 상태 규칙
- 결과를 저장하면 상태가 자동으로 “자료 있음”이 됩니다.
- 그 밖의 상태는 사용자가 직접 바꿉니다.
- 마지막 기록을 삭제하면 “자료 있음”이 “미업로드”로 돌아갑니다.
- “계획 없음”(하지 않기로 함)과 “미업로드”(아직 안 함·미등록)는 다른 상태입니다.

### 전기화학 조건: 고정 항목과 갱신 항목
- **측정 당시 고정**(snapshot): 잉크 조성, 도포 방식, 로딩, 전해질, 기준·상대 전극, 회전 속도
  - 측정을 저장할 때 `conditions.session_snapshot`으로 복사됩니다.
  - 세션 값을 나중에 바꿔도 과거 측정 조건은 바뀌지 않습니다.
  - 화면에서 차이를 강조해 보여줍니다.
- **세션 따라 갱신**(live): RDE 번호(기본 “모름”), 세션 이름, 메모
  - 나중에 확인한 정보를 과거 측정에도 반영합니다.
- 기본값: RDE “모름”, 잉크 “기존”, 도포 “2 µL × 1회”, 로딩 0.222 mg (`source=default`)

## 4. 계산과 근거 보존
모든 계산은 `calc.js`의 순수 함수에서 합니다. 저장할 때 `computed.metrics.{key} = {value, unit, formula, inputs}` 형태로 식과 입력을 함께 남깁니다.

| 분석 | 계산 | 비고 |
|---|---|---|
| XRD | GS = K·λ/(rad(FWHM)·cos(rad(2θ/2))), SI = 면적/FWHM | (110)·(101) 라벨 피크에서 지표 생성. 4번째 피크는 요약에서 제외(기록은 유지). 입력 GS는 원본으로 별도 보존 |
| XRD 배경 | 사용자 배경점(가장 가까운 데이터점에 붙음) → 자연 3차 스플라인 | 원본 XY와 배경점만 저장하고 보정 곡선은 재계산 |
| BET | 모든 연속 구간의 BET 직선 → R², C, Qm, S = Qm × 4.3525 | 기본 선택 규칙과 탈락 사유 표시. 후보가 없으면 미계산. 보고서 값(`values.bet_ssa`)과 재계산 값(`computed.bet_ssa_recalc`) 분리 |
| XRF | 순도 = Σ주성분/Σ보고 성분 × 100 | 산화물 → 원소 질량분율 환산식 기록. 미보고는 “보고 없음” |
| PSA | Span = (D90 − D10)/D50 | D90 10–25 µm은 참고 범위 |
| TGA | DTG = −d(질량%)/dT, 스무딩(Savitzky–Golay 2차 기본 21점) | 원본 DTG 함께 표시. 수분 = [m(T1) − m(T2)]/m₀ × 100, 근거 필수 |
| CV | 사이클 분리: cycle 열 우선, 없으면 전위 꼭짓점 또는 시작 전위 재통과 | 사이클 번호·행 구간·불완전 여부 표시 |
| ECSA | 선택 전위에서 정방향 i_a, 역방향 i_c → (i_a − i_c)/2 대 v 기울기 = Cdl | 산화·환원 기울기 별도 표시. ECSA = Cdl/Cs, Cs 근거 필수(기본 0.035 mF/cm², 문헌 일반값 가정) |

## 5. 비교와 패턴

### 비교 흐름
1. 샘플 선택
2. 상태 매트릭스 확인(공통 / 일부 / 없음)
3. 분석 선택
4. 결과 확인
   - 조건 차이 표: 기본값 여부도 표시합니다.
   - 수치 표와 지표 막대그래프
   - XRF 불순물 그래프
   - 곡선 비교

### 곡선 비교
- 검색·필터를 바꿔도 선택은 유지됩니다.
- “그래프에 적용”을 눌러야 그래프가 다시 그려집니다.
- 색은 샘플 색입니다. 같은 샘플의 여러 곡선은 선 모양으로 구분합니다.
- 범례는 그래프 밖에 줄바꿈으로 배치합니다.
- XRD는 정규화 여부와 배경 보정 여부를 선택할 수 있고, 그래프에 처리 방식을 표시합니다.

### 패턴 탐색
- **특징**: 분석 지표(샘플별 평균, 여러 측정이면 경고)와 합성 조건 수치(기본값이면 경고)
- **판단**: n < 3이면 판단 불가, n < 5이면 참고만입니다. 그 이상은 상관 강도를 서술하며 인과가 아님을 명시합니다.
- **결측**: 값이 없는 샘플은 0으로 채우지 않고 제외하며, 어떤 샘플이 제외됐는지 표시합니다.
- **확인할 쌍**: 같은 분석 안의 지표끼리(예: FWHM과 GS)는 당연히 연관되므로 제외합니다. 순위는 |r|에 n 가중을 적용해 정합니다.
- **다음 측정 제안**: 빠진 측정을 샘플과 현재 상태별로 보여줍니다.
- 관찰은 해석(근거, 불확실성, 다음 측정 포함)으로 저장할 수 있습니다.

## 6. AI 맥락 내보내기 (`GET /api/export/context`)
`format: pattern-seeker-context v1`. 샘플별로 다음 항목을 내보냅니다.
- 관계, 시리즈, 합성 단계(값과 출처), 분석 상태
- 측정: `conditions`, `recorded_values`, `computed_values`(식 포함), `provenance`, 원시 데이터 요약
- `user_interpretations`, `ai_hypotheses`

`reading_guide`에 결측, 출처 코드, 상관과 인과의 구분, 상태의 의미를 명시합니다.

## 7. 다음 단계 (미구현)
- **XRD Gaussian 피팅**: 기본 7개, 피크 추가·삭제·조정. 자동 결과는 “피팅 추정”으로 표시하고 실측과 구분합니다.
- **BET 예측**: 실측 BET와 Cdl 쌍으로 보정·검증하고 적용 범위와 불확실성을 표시합니다. 데이터가 적거나 범위 밖이면 경고합니다.
- **기존 운영 데이터 가져오기**: 이전 Pattern Seeker 데이터 형식이 확보되면 매핑 후 사본 DB에서 검증하고 적용합니다.
- 각 분석에서 사이클·곡선 단위로 지표 추출(LSV 과전압 등)
- 첨부 파일 일괄 경로 재지정(보관소 폴더 이동 시)
