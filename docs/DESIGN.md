# Pattern Seeker 설계

## 1. 문제와 목표
연구자가 합성 조건과 XRD·BET·XRF·PSA·TGA·pH·전기화학 결과를 머릿속에서 연결하던 부담을 줄입니다. 저장에서 그치지 않고 다음을 목표로 합니다.

- **연결**: 샘플 ↔ 파생·분기·결합 이력 ↔ 합성 단계 ↔ 분석 결과 ↔ 조건·출처
- **비교**: 여러 샘플의 공통 분석과 조건 차이를 한 화면에서 봅니다.
- **판단 경계**: 데이터로 확인되는 패턴과 데이터가 부족해 판단할 수 없는 부분을 구분합니다.
- **AI 가독성**: 기록값, 계산값, 해석, 가설을 분리하고 단위와 출처를 명시해 저장합니다.

## 2. 구조

```
브라우저 (app/static: 바닐라 JS, SVG 그래프)
   │ JSON (127.0.0.1:8765)
Python 표준 라이브러리 서버 (app/server.py)
   │
SQLite (data/pattern_seeker.db) + data/backups + data/files
```

로컬 서버를 두는 이유는 두 가지입니다.
1. 개인 보관소 경로의 파일 존재 여부를 확인하고 읽으려면 서버가 필요합니다. 브라우저만으로는 할 수 없습니다.
2. SQLite에 안전하게 쓰고 백업·복구하려면 서버가 필요합니다.

요청은 전역 락으로 직렬화합니다. 단일 사용자 로컬 앱이므로 복구 중 동시 쓰기를 막는 쪽을 택했습니다.

## 3. 데이터 모델 (스키마 v1)

| 테이블 | 내용 |
|---|---|
| `samples` | 최종 분말 단위 샘플. 색(`color`)은 모든 그래프에서 같은 색으로 씁니다. 소프트 삭제(`deleted_at`) |
| `sample_links` | 관계(DAG, 다대다): `relation`(파생/분기/결합/재처리/기타), `branch_point`(갈라진 시점), 순환 방지 |
| `series`, `series_members` | 연구 묶음. 관계와 독립 |
| `synthesis_steps`, `reagents` | 합성 단계. `params` = `{키:{value,unit,label,source}}`. 시약 제조사 기본 H사(`supplier_source='default'`) |
| `analysis_types` | 분석 종류 레지스트리 (`config.tool/fields/metrics/default_conditions`) |
| `sample_analysis_status` | 샘플×분석 상태. 행이 없으면 “미업로드” |
| `measurements` | 측정 기록: `conditions`, `values`, `computed`, `source`, `measured_on(_source)`, `seq`, `ec_session_id` |
| `datasets` | 원시 곡선(열 배열). 처리 조건(배경점, 스무딩, 단위, 사이클 분리)은 `meta`. 원본은 변형하지 않음 |
| `attachments` | `link`(경로·크기·수정 시각) 또는 `copy`(sha256, data/files). 상태: 확인됨 / 경로 깨짐 / 파일 변경됨 |
| `ec_sessions` | 전극/세션 조건 |
| `interpretations` | `user_interpretation` / `ai_hypothesis` + `evidence`(근거, 조건 차이, 데이터 부족, 불확실성, 다음 측정) |
| `settings` | 기본값 (시약 제조사, 열처리, 전기화학) |
| `audit_log` | 생성·수정·삭제 전후 상태 |

### 상태 규칙
- 결과를 저장하면 상태가 자동으로 “자료 있음”이 됩니다.
- 그 밖의 상태는 사용자가 직접 바꿉니다.
- 마지막 기록을 삭제하면 “자료 있음”이 “미업로드”로 돌아갑니다.
- “계획 없음”(하지 않기로 함)과 “미업로드”(아직 안 함·미등록)는 다른 상태입니다.

### 전기화학 조건: 고정 항목과 갱신 항목
- **측정 당시 고정**(snapshot): 잉크 조성, 도포 방식, 로딩, 전해질, 기준·상대 전극, 회전 속도
  - 측정을 저장할 때 `conditions.session_snapshot`으로 복사됩니다.
  - 세션 값을 나중에 바꿔도 과거 측정 조건은 바뀌지 않습니다.
  - 화면에서 차이를 강조해 보여줍니다.
- **세션 따라 갱신**(live): RDE 번호(기본 “모름”), 세션 이름, 메모
  - 나중에 확인한 정보를 과거 측정에도 반영합니다.
- 기본값: RDE “모름”, 잉크 “기존”, 도포 “2 µL × 1회”, 로딩 0.222 mg (`source=default`)

## 4. 계산과 근거 보존
모든 계산은 `calc.js`의 순수 함수에서 합니다. 저장할 때 `computed.metrics.{key} = {value, unit, formula, inputs}` 형태로 식과 입력을 함께 남깁니다.

| 분석 | 계산 | 비고 |
|---|---|---|
| XRD | GS = K·λ/(rad(FWHM)·cos(rad(2θ/2))), SI = 면적/FWHM | (110)·(101) 라벨 피크에서 지표 생성. 4번째 피크는 요약에서 제외(기록은 유지). 입력 GS는 원본으로 별도 보존 |
| XRD 배경 | 사용자 배경점(가장 가까운 데이터점에 붙음) → 자연 3차 스플라인 | 원본 XY와 배경점만 저장하고 보정 곡선은 재계산 |
| BET | 모든 연속 구간의 BET 직선 → R², C, Qm, S = Qm × 4.3525 | 기본 선택 규칙과 탈락 사유 표시. 후보가 없으면 미계산. 보고서 값(`values.bet_ssa`)과 재계산 값(`computed.bet_ssa_recalc`) 분리 |
| XRF | 순도 = Σ주성분/Σ보고 성분 × 100 | 산화물 → 원소 질량분율 환산식 기록. 미보고는 “보고 없음” |
| PSA | Span = (D90 − D10)/D50 | D90 10–25 µm은 참고 범위 |
| TGA | DTG = −d(질량%)/dT, 스무딩(Savitzky–Golay 2차 기본 21점) | 원본 DTG 함께 표시. 수분 = [m(T1) − m(T2)]/m₀ × 100, 근거 필수 |
| CV | 사이클 분리: cycle 열 우선, 없으면 전위 꼭짓점 또는 시작 전위 재통과 | 사이클 번호·행 구간·불완전 여부 표시 |
| ECSA | 선택 전위에서 정방향 i_a, 역방향 i_c → (i_a − i_c)/2 대 v 기울기 = Cdl | 산화·환원 기울기 별도 표시. ECSA = Cdl/Cs, Cs 근거 필수(기본 0.035 mF/cm², 문헌 일반값 가정) |

## 5. 비교와 패턴

### 비교 흐름
1. 샘플 선택
2. 상태 매트릭스 확인(공통 / 일부 / 없음)
3. 분석 선택
4. 결과 확인
   - 조건 차이 표: 기본값 여부도 표시합니다.
   - 수치 표와 지표 막대그래프
   - XRF 불순물 그래프
   - 곡선 비교

### 곡선 비교
- 검색·필터를 바꿔도 선택은 유지됩니다.
- “그래프에 적용”을 눌러야 그래프가 다시 그려집니다.
- 색은 샘플 색입니다. 같은 샘플의 여러 곡선은 선 모양으로 구분합니다.
- 범례는 그래프 밖에 줄바꿈으로 배치합니다.
- XRD는 정규화 여부와 배경 보정 여부를 선택할 수 있고, 그래프에 처리 방식을 표시합니다.

### 패턴 탐색
- **특징**: 분석 지표(샘플별 평균, 여러 측정이면 경고)와 합성 조건 수치(기본값이면 경고)
- **판단**: n < 3이면 판단 불가, n < 5이면 참고만입니다. 그 이상은 상관 강도를 서술하며 인과가 아님을 명시합니다.
- **결측**: 값이 없는 샘플은 0으로 채우지 않고 제외하며, 어떤 샘플이 제외됐는지 표시합니다.
- **확인할 쌍**: 같은 분석 안의 지표끼리(예: FWHM과 GS)는 당연히 연관되므로 제외합니다. 순위는 |r|에 n 가중을 적용해 정합니다.
- **다음 측정 제안**: 빠진 측정을 샘플과 현재 상태별로 보여줍니다.
- 관찰은 해석(근거, 불확실성, 다음 측정 포함)으로 저장할 수 있습니다.

## 6. AI 맥락 내보내기 (`GET /api/export/context`)
`format: pattern-seeker-context v1`. 샘플별로 다음 항목을 내보냅니다.
- 관계, 시리즈, 합성 단계(값과 출처), 분석 상태
- 측정: `conditions`, `recorded_values`, `computed_values`(식 포함), `provenance`, 원시 데이터 요약
- `user_interpretations`, `ai_hypotheses`

`reading_guide`에 결측, 출처 코드, 상관과 인과의 구분, 상태의 의미를 명시합니다.

## 7. XRD Gaussian 피팅 (2단계)
- **피팅 대상**: 배경점이 2개 이상이면 배경 보정 데이터, 없으면 원본 강도입니다. 원본 강도에 피팅할 때는 경고를 표시합니다.
- **초기값**: 스무딩한 곡선의 국소 최대 중 높은 순으로 n개(기본 7개, 최소 간격 0.4°)를 고르고, FWHM은 반치폭으로 추정합니다. 라벨은 2θ 순서대로 (110), (101)입니다.
- **피팅**: Levenberg–Marquardt, 해석적 야코비안을 씁니다. 높이는 0 이상, FWHM과 중심은 범위 안으로 제한합니다. 값별로 고정할 수 있고, 3000점 넘으면 등간격으로 줄여서 피팅합니다.
- **조정**: 피크 추가·삭제, 중심·FWHM·높이 직접 수정(“수정됨” 표시), 범위 지정, 성분 곡선과 잔차 그래프를 제공합니다.
- **저장**: `datasets.meta.fit`에 저장합니다.
  - 저장 항목: model, formula, status, basis, 배경점 스냅샷, range, peaks, R², 반복 수, 수렴 여부
  - 배경점이 바뀌면 `stale`로 표시하고, 결과를 피크 표로 가져오는 것을 막습니다.
- **피크 표로 가져오기**: 면적 = H × w × √(π/(4ln2))로 계산하고 `source='fit'`으로 표시합니다. GS·SI의 `inputs.peak_source`에도 피팅 추정임을 남깁니다.

## 8. BET 예측 (검증형, 2단계)
- **x 값**: Cdl/로딩(mF/mg, 기본) 또는 Cdl(mF)입니다. 실측 BET는 보고서 값 우선, 보고서 값만, 재계산 값만 중에서 고릅니다. 한 샘플에 측정이 여러 개면 평균을 씁니다.
- **모델**: 최소제곱 직선 y = a + b·x
- **검증**: LOO RMSE와 평균 오차 %, R², n, 학습 범위를 표시합니다.
- **표시 규칙**

  | 조건 | 동작 |
  |---|---|
  | n < 3 | 관계도 보여주지 않음 |
  | n < 5 | 관계는 참고로만 보여주고 예측값은 표시 안 함 |
  | LOO 평균 오차 > 30 % | 신뢰도 낮음 경고 |
  | 학습 범위 밖 | 예측값을 회색으로 표시, “외삽” 경고, 예측구간 대신 “신뢰 불가” |

- **예측구간**: 95 %, ŷ ± t(n−2)·s·√(1 + 1/n + (x − x̄)²/Sxx)
- **조건 경고**: 전해질 혼재, 선택 전위 불일치, 기본값 로딩, 측정 평균 사용, 보고서·재계산 BET 혼재
- **저장 안 함**: 예측값은 화면에만 표시합니다. 실측 BET를 추가하면 보정이 자동으로 갱신됩니다.

## 9. XRF 성적서 (Rigaku SQX) 가져오기 (3단계)
실제 성적서 5건(A07_2, A07 no 침전, 26B04, HMQtz 100cc Stir/no Stir)으로 규칙을 맞췄습니다.
- **PDF 텍스트**: Microsoft Print to PDF 양식(CID 폰트 Identity-H + ToUnicode, Flate)을 `app/pdftext.py`로 읽습니다.
  - 글리프 폭(/W)으로 글자별 x를 계산해 단어 단위로 줄을 재구성합니다. 그래서 다른 폰트로 그려진 한글 샘플명(“A07 no 침전”)도 제자리에 들어갑니다.
  - ObjStm·암호화·스캔 PDF는 지원하지 않아 pypdf나 OCR로 넘깁니다.
- **양식 인식**: “Component Result Unit” 헤더가 있으면 SQX로 봅니다.
  - 헤더: Sample(전각 → NFKC), Date analyzed, 출력 시각, Application, Sample type, Balance, film/impurity corr., File
  - 성분 행: 번호, 성분, 결과, 단위, 검출한계, 분석선, 강도, w/o normal(정규화 전)
- **값 상태**: “Trace”를 검출한계 값(예: 0.00000)으로 잘못 읽던 문제를 고쳤습니다. 상태별로 저장하고 값은 null입니다.
- **원자량**: 원자량 표를 주요 원소 전체로 늘렸습니다. 표에 없는 원소(예: Tl)가 조용히 빠지던 문제를 고쳤습니다.
- **샘플명 비교**: NFKC, 소문자 변환 후 영숫자·한글만 남긴 키로 비교합니다. “＃Ａ０７＿２”는 “A07_2”와 같은 샘플로 봅니다. 성적서 샘플명이 앱 샘플명과 다르면 경고합니다.
- **일괄 가져오기**(`#/import/xrf`)
  - 폴더 경로(경로 연결 첨부) 또는 파일 선택(복사 첨부)으로 넣습니다.
  - 미리보기에서 샘플을 자동 매칭합니다. 매칭이 없으면 “건너뛰기”가 기본이고, 새 샘플 생성은 사용자가 고릅니다.
  - 같은 파일명 또는 같은 Date analyzed가 있으면 중복으로 보고 건너뛰기가 기본입니다.
  - 저장 직전에 자동 백업하고, 행별 성공·실패를 표시합니다.

## 10. XRF Metal basis 순도 · 필름 보정 · BET 보고서 (4단계)

### XRF
- **순도**: 사용자 예시(Ir 93.7, Na·Al·Si·K·Ni·Zn·Rb·Sn 합 0.4731, Cl·I·S 제외)로 검증했습니다. 결과 99.4976 → 99.50 %입니다.
- **계산 근거 보존**: 주성분 합, 금속 불순물 목록과 합, 전체 금속량, 제외한 성분을 `computed.details.purity_breakdown`과 `metrics.purity.inputs`에 남깁니다.
- **필름 보정**: “Sample film corr.” 칸에 필름 이름(예: P.E.2.5u(N))이 있으면 “보정 있음”으로 봅니다. Impurity corr., Application, Sample type과 함께 측정 조건에 저장합니다.

### BET (Micromeritics MicroActive, TriStar II 3020)
원자료 보고서 2건(#A05-INDI, #A07-NOX-GAS)과 케이코어솔루션 결과표 1건(8종)으로 규칙을 맞췄습니다.
- **원자료 보고서에서 읽는 것**
  - 헤더: 시료명, Started/Completed(오전·오후 처리), 시료 질량, 흡착 기체, bath 온도, 평형 간격, SMP 파일 경로
  - Summary: BET, 단일점 비표면적, t-plot 미세기공·외부 면적, 총 기공 부피, t-plot 미세기공 부피, BJH 흡착·탈착 부피, 평균 기공 직경, HK
  - BET Report: 계산 구간 점들, Slope, 절편, C, Qm, 상관계수
  - t-plot: 두께 범위와 두께 식
  - 등온선 표: 흡착과 탈착을 모두 읽고, 절대압과 포화압도 함께 저장합니다.
- **결과표에서 읽는 것**: 시료명과 숫자 열(헤더 순서로 항목을 매핑), 완료일자, 문서번호, 전처리 조건, 공칭 BET 구간
- **재계산 검증**: 보고서와 같은 구간으로 앱이 다시 계산하면 #A05 269.2052(보고서 269.2050), #A07 270.9372(보고서 270.937)입니다.
- **앱 규칙의 한계**: R² 최고 규칙은 4–6점 구간을 골라 270.23·271.99가 나옵니다. 그래서 보고서 구간을 기본으로 쓰고, 앱 규칙 결과는 참고로 표시·저장합니다.
- **미세기공성 경고**: t-plot 미세기공 면적 / BET를 `micro_area_ratio`로 계산합니다. 50 %를 넘으면 구간 민감도 경고를 표시합니다(A05 96.5 %, A07 95.4 %).
- **일괄 가져오기**(`#/import/bet`)
  - 같은 시료의 원자료와 결과표 행은 하나의 기록으로 합칩니다. 전처리 조건과 공칭 구간은 결과표에서 가져오고, 결과표 파일도 첨부합니다.
  - 원자료가 없으면 결과표 값만 저장합니다. 완료일자는 분석일이 아니므로 측정일로 쓰지 않습니다.
