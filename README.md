# Pattern Seeker

수전해 촉매 연구용 **로컬·오프라인 연구 기록·비교 도구**입니다. 샘플의 합성 이력과 XRD·BET·XRF·PSA·TGA·분말 pH·전기화학 데이터를 연결해, 여러 샘플 사이의 패턴과 “데이터가 부족해 판단할 수 없는 부분”을 구분해 보여줍니다.

## 실행 (Windows)

1. Python 3.8 이상을 설치합니다. 설치할 때 “Add python.exe to PATH”를 체크하세요. 추가 패키지는 필요 없습니다.
2. `run.bat`을 더블클릭합니다. 브라우저에서 `http://127.0.0.1:8765`가 열립니다.
3. 검은 창(서버)을 닫으면 앱이 종료됩니다. 인터넷 연결은 필요 없습니다.

다른 OS에서는 `python3 app/server.py`로 실행합니다.

선택 기능:
- PDF 텍스트 추출은 내장 기능입니다. 장비 소프트웨어의 “인쇄→PDF” 성적서(예: Rigaku SQX)는 추가 설치 없이 읽습니다. 내장 추출기로 못 읽는 PDF가 있을 때만 `pip install pypdf`를 설치하세요.
- Tesseract + `pip install pytesseract pillow`: 캡처 이미지 OCR을 씁니다. 없으면 값을 직접 입력합니다.

## 데이터 위치와 백업

| 경로 | 내용 |
|---|---|
| `data/pattern_seeker.db` | 모든 기록 (SQLite) |
| `data/backups/` | 백업 DB와 검증 정보(`.json`) |
| `data/files/` | “앱에 복사” 방식으로 첨부한 파일 |

- 다른 위치를 쓰려면 환경 변수 `PATTERN_SEEKER_DATA`로 지정합니다.
- **설정·백업** 화면에서 백업, 백업 검증(무결성과 행 수 비교), 특정 시점으로 복구를 할 수 있습니다.
- 복구하기 전과 스키마 마이그레이션하기 전에는 자동으로 백업합니다.
- DB 백업에 `data/files/` 폴더는 들어가지 않습니다. 이 폴더는 따로 보관하세요.
- “경로만 연결”한 첨부의 원본은 사용자의 보관소에 그대로 있습니다.

## 주요 기능

- **샘플과 관계**
  - 최종 분말 단위로 샘플을 등록합니다.
  - 파생·분기·결합·재처리 관계는 다대다로 연결하고 계보 맵으로 봅니다.
  - 시리즈(분류)는 관계와 별개로 관리합니다.
- **합성 이력**
  - 단계, 조건, 시약, 공정 메모를 기록합니다.
  - 기본값(시약 H사, 열처리 450 °C·승온 50분·유지 30분)은 “기본값”으로 표시해 실제 조건과 구분합니다.
- **분석 상태**: 자료 있음 / 자료 없음 / 계획 없음 / 의뢰 중 / 미업로드(기본값)
- **분석별 도구**

  | 분석 | 기능 |
  |---|---|
  | XRD | 피크 표 붙여넣기 → (110)·(101) GS·SI 계산, XY 그래프, 스플라인 배경 보정, 정규화, Gaussian 피팅(기본 7개, “피팅 추정” 표시) |
  | BET | Micromeritics MicroActive 보고서 PDF 직접 읽기(요약·등온선·BET 계산 구간·t-plot·BJH·HK), 분석기관 결과표 읽기, 보고서 구간으로 앱 재계산·검증, 구간 검토(R² ≥ 0.995, C > 0, Rouquerol 기준), 미세기공성 경고, 일괄 가져오기 |
  | XRF | Rigaku SQX 성적서 PDF 직접 읽기(검출한계·분석선·Date analyzed·필름 보정 여부 포함), Trace·불검출은 0 대신 값 없음, Metal basis 순도(비금속 제외), Cl·Si·Na(산화물은 원소로 환산), 여러 성적서 일괄 가져오기 |
  | PSA | D10/D50/D90, Span, D90 참고 범위 |
  | TGA | 질량·DTG(스무딩, 원본 곡선 보존), 수분 함량(구간과 근거 필수) |
  | 전기화학 | CV 사이클 자동 분리, 측정 순서, 전극/세션 조건(고정 항목과 갱신 항목 구분) |
  | ECSA/Cdl | scan rate별 전류 선택을 그래프로 확인, Cs 가정값과 근거 기록 |

- **비교**
  - 샘플을 고르면 분석 상태 매트릭스를 보여주고, 그다음 분석을 고릅니다.
  - 조건 차이, 수치 표, 막대그래프, 곡선 비교를 제공합니다. 곡선 비교는 “적용” 버튼을 눌러야 그래프가 바뀝니다.
- **패턴 탐색**
  - 데이터 충분성과 두 특징의 상관(n, r, ρ)을 보여주고, 판단 가능 여부를 함께 표시합니다.
  - 확인해 볼 쌍과 다음 측정을 제안합니다.
- **BET 예측(검증형)**: 실측 BET와 Cdl/로딩으로 보정하고 교차검증합니다. 학습 샘플 5개 이상일 때만 예측값을 보여주며, 예측구간과 학습 범위 밖 경고를 함께 표시합니다.
- **AI 맥락 내보내기**: 기록값, 계산값(식 포함), 출처, 연구자 해석, AI 가설을 분리한 JSON으로 내보냅니다.
